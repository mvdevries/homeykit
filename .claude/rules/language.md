# Rule: the working language of this repository is English

- **Everything in this repository is in English**: code (names of variables, functions, classes, files, CSS
  classes, setting keys and log lines), commit messages, branch names, pull request titles and descriptions,
  issues, documentation (`README.md`, `CONTRIBUTING.md`, `SECURITY.md`, `CLAUDE.md`) and test names.
- The only exceptions are the texts shown to users. They live in `locales/en.json` and `locales/nl.json`
  (and the store texts `README.txt` and `README.nl.txt`), never hardcoded in `settings/`.
- Chat with the maintainer may be in any language; what ends up in the repository is English.
